本文件由 server/verify.py 在官方 PowerContext Server 运行后自动生成（真实运行日志）。

运行方式（见 README.md）：
    pip install "powercontext[cli,builtin]>=1.4"
    python memory_server.py          # 启动官方 PowerContext Server :8000
    python verify.py                 # 官方 SDK 调用 remember_memory / search_memory

注意：早期版本本文件保存的是"自制 SQLite 兼容实现"的日志，已废弃。
现统一改为官方 PowerContext 接入，验证证据以官方 SDK（PowerContextClient）实测输出为准。
