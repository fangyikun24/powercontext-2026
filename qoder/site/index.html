StudyMate · 学习提效助手

把"薄弱点"变成可复用的记忆 —— 记录、检索、复习，让每次学习都有上下文延续。

项目简介

StudyMate 是一个面向学生与科研人员的学习提效工具。它的核心不是"记笔记"，而是记忆复用：当你发现一个知识点没学透，用一条命令把它标记为薄弱点；之后每次复习，StudyMate 都会把它连同相关笔记一起召回。记忆由 PowerContext 持久化，重启后依然存在。

解决的问题

  • 学了就忘：薄弱点散落各处，难以按需召回 → 集中存入记忆层，随时检索。
  • 复习没重点：不知道哪些点薄弱、该补哪里 → review 一键输出复习清单。
  • 笔记难检索：关键词搜不到 → 记忆 + 笔记双路召回，覆盖更全。

核心功能

📝 记笔记

studymate note add，支持标签分类。

🔍 检索笔记

studymate note search，全文计分检索。

⚠️ 记录薄弱点

studymate weakness add，写入 PowerContext 记忆。

📖 一键复习

studymate review，合并薄弱点与笔记。

体验演示

真实运行输出（本机实测，详见验证记录）：

$ studymate weakness add "机器学习-过拟合" "训练好验证差，对策：正则化+早停"
✔ 薄弱点已记入记忆

$ studymate weakness list
记忆中已记录的薄弱点：
  1. 机器学习-过拟合：训练好验证差，对策：正则化+早停

体验入口

本地运行（仅标准库依赖）：

git clone <你的仓库地址> && cd qoder/studymate
python -m studymate.cli.main review "过拟合"

可选：设置 POWERCONTEXT_URL 接入 PowerContext server；未设置自动使用本地 SQLite，功能完整。
