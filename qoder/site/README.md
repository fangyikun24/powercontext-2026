# Qoder Sites 发布说明

## 网站内容

`site/index.html` 为项目网站完整页面（单文件，无外部依赖），包含赛题要求的全部要素：

| 要求 | 位置 |
|---|---|
| 项目简介 | 首页 hero + 简介 section |
| 解决的问题 | "解决的问题" section |
| 核心功能 | "核心功能" section |
| 演示视频或截图 | "体验演示" section（本机实测输出实录，发布时可替换为录屏） |
| 代码仓库链接 | "代码仓库" section（发布前填入你的 fork 地址） |
| 体验入口 | "体验入口" section（含运行命令） |

## 发布步骤（Qoder Sites）

1. 打开 Qoder，进入 **Sites**（发布）功能；
2. 上传 `site/index.html`（或复制内容到 Sites 编辑器）；
3. 设置可见范围：**任何人都可访问**（验收要求未登录可开）；
4. 发布后复制网站网址，回填到：
   - `records/QODER_DEV_LOG.md` 末尾"Qoder Sites 网址"处；
   - 提测平台提交信息中。

## 发布前核对清单

- [ ] 仓库链接（fork 后真实地址）已填入
- [ ] 演示截图/录屏已放入（可选，发布后可补）
- [ ] 可见范围=任何人
- [ ] 网址已记录
